# 🧮 JavaScript Age Calculator

A simple and elegant web application that calculates a user's exact age in years, months, and days based on their date of birth.

## 🔧 Technologies Used
- **HTML5** – Structured the content and form elements  
- **CSS3** – Designed a responsive and visually appealing layout using gradients and custom styling  
- **JavaScript (Vanilla)** – Handled date calculations, DOM interactions, and user input validations

## 🎯 Features
- 📅 **User-Friendly Input**: Accepts date of birth via a calendar picker, with future dates automatically disabled  
- 🧠 **Accurate Calculations**: Computes exact age including years, months, and days, accounting for leap years and varying month lengths  
- 🎨 **Clean UI**: Stylish interface using modern CSS with a soft color palette and intuitive layout  
- ⚡ **Instant Output**: Displays result immediately on button click without page reload
